# File Analysis

## File Name
invoice.pdf

## Actual File Type
Plain text (ASCII text), not a PDF.

## Observation
The filename uses a .pdf extension, but file-type analysis confirms
the actual content is plain text.

## Security Relevance
File extensions are only a label chosen by whoever created the file —
they are not proof of what a file actually is. Attackers can rename
malicious files (e.g., an executable) to look like a harmless document.
Analysts must verify the real file type, not trust the extension alone.
