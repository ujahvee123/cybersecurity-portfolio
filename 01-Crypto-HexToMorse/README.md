# Crypto Challenge: Hex → Morse Code Decoding

## Objective
Decode a hex-encoded string to recover the original plaintext message.

## Tools Used
- CyberChef (web-based data analysis tool)

## Methodology
1. Identified the input as hex-encoded data based on its byte pattern.
2. Used CyberChef's "From Hex" recipe to decode the hex string.
3. The output revealed a Morse code pattern (dots and dashes).
4. Applied CyberChef's "From Morse Code" recipe to decode the Morse code into plaintext.

## Result
**Plaintext:** THIS IS A WAY DOUBLE ENCRYPTION CAN BE DONE.

## Encoding Chain
Hex → Morse Code → Plaintext (double encoding)
